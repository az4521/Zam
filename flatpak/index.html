Zam

Matrix client · Flatpak v@VERSION@

Install

Install Zam opens in your software centre, or from a terminal: 

flatpak install --user @BASE@/zam.flatpakref

Add the repository

To browse or update it as its own remote:

flatpak remote-add --user --if-not-exists zam @BASE@/zam.flatpakrepo
flatpak install --user zam moe.crafty.matrix

Update

flatpak update

The runtime comes from Flathub, which is added automatically if you don't have it. Source and other builds: github.com/az4521/Zam.
